# لوحة تحكم دردشات رحوي والمراسلات — القائمة 05 بلدية الرحوية

لوحة تحكم ويب سريعة ومستقلة، مخصصة لإدارة ومتابعة المحادثات المباشرة للمساعد الذكي «رحوي» واستمارات التواصل الواردة من المواطنين في حملة الانتخابات البلدية لبلدية الرحوية، ولاية تيارت.

---

## المميزات التقنية
- **ربط مباشر ولحظي مع Supabase:** جلب وتحديث آلي للمحادثات كل 20 ثانية دون الحاجة لإعادة تحميل الصفحة.
- **تجميع المحادثات لكل زائر:** يتم تجميع كافة رسائل الزائر الواحد في سجل واحد مرتب زمنياً عبر معرّف الجلسة ورقم الهاتف.
- **التعرف على الشبكات والموقع:** كشف دقيق لمزود الخدمة (اتصالات الجزائر، موبيليس، أوريدو، جازي) ونوع الاتصال والولاية.
- **كشف دقيق لنوع الجهاز:** استخراج اسم وطراز الجهاز (Samsung Galaxy, Xiaomi Redmi, iPhone, PC...) بدقة واحترافية.
- **تصدير Excel/CSV:** تصدير كافة المحادثات والبيانات بضغطة زر بصيغة CSV متوافقة مع Excel باللغة العربية (UTF-8 BOM).
- **أمان وخصوصية:** ملف `robots.txt` يحظر فهرسة اللوحة على كافة محركات البحث لحماية بيانات المواطنين.

---

## النشر والتشغيل
- تطبيق ويب ثابت بالكامل (Pure Client-side Single Page Application).
- الملف الرئيسي: `index.html`.
- جاهز للنشر المباشر في مستودع GitHub خاص أو على **Vercel** / **Netlify** برابط أو نطاق فرعي مخصص (مثل: `dash.example.com`).
